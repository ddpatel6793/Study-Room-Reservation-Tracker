# Study-Room-Reservation-Tracker
<br>COP 3003 C++  group project for managing study room reservations 
<br>Developement Enviornment
<br>Operating System: Windows
<br>IDE: Microsoft Visual Studio
<br>Compiler: MSVC (Microsoft C++ compiler)
<br>C++ standard: C++20
<br> Build And Run: 
<br> 1. Clone the GitHub repository
<br> 2. Install Qt 6.12.0 with the compatible MSVC kit and configure Qt Visual Studio Tools.
<br> 3. Open StudyRoomTracker/StudyRoomTracker.slnx in Visual Studio 2022.
<br> 4. Select Debug and x64.
<br> 5. Set StudyRoomTrackerGUI as the startup project.
<br> 6. Press CTRL + SHIFT + B to build
<br> 7. CTRL + F5 to run the GUI application 
<br> Current GUI Progress
<br> View All Rooms: Implemented and tested successfully.
<br>Reserve a Room: Planned; not yet connected to GUI.
<br>Cancel a Reservation: Planned; not yet connected to GUI.
<br> The View All Rooms button displays the room number, floor, capactity, and availability of all 12 rooms.
