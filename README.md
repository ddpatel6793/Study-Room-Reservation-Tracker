# Study-Room-Reservation-Tracker
<br>COP 3003 C++  group project for managing study room reservations 
<br>Operating System: Windows
<br>IDE: Microsoft Visual Studio
<br>Compiler: MSVC (Microsoft C++ compiler)
<br>C++ standard: C++20
<br>Dependencies: No additional libraries currently used
<br> Build And Run: 
<br> 1. Clone the GitHub repository
<br> 2. Open studyRoomTracker.slnx in Microsoft Visual Studio
<br> 3. Select Debug and x64.
<br> 4. Press CTRL + SHIFT + B to build
<br> 5. CTRL + F5 to run the program
